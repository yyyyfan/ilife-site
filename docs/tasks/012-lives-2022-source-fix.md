## 来源规则（比 010 严格）
1. 主出处优先级：@iLiFE_official 的出演告知、当日「本日の出演」、タイムテーブル帖 > 官网 schedule > 主办方或会场官网的活动页。
2. Eventernote / LiveFans 只能在**打开页面并确认**页面上有 iLiFE!、日期和会场都一致之后才能使用，并在 note 标 `仅非官方来源`。**不得拼接或猜测 events/数字**，只用搜索到并实际打开过的 URL。
3. 推文出处必须是正文或图片里能看到这场演出的帖子。只讲特典、只讲别的活动的帖子不算。
4. 月度排期图作为唯一出处时，在 note 注明“来源为月度排期图”。
5. 会场容纳人数只能填在能直接看到这个数字的具体页面 URL 上（写入 sources），首页或找不到就留空。地址同理。
6. 日期一律用 JST（推文时间由 post ID 换算）。取消或延期的场次保留并注明。查不到的字段留空，找不到任何真实出处的场次不要收录。
