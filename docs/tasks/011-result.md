# 011 2020–2021 年演出出处替换为官方来源 结果报告

## 1. 任务概述

本任务对 iLiFE! 2020–2021 年共 **140 场** 公演的出处进行了全面核查与官方来源升级替换：
- **成功替换为官方来源**：**46 场**（涵盖 @iLiFE_official 官方推文告知/当日御礼、主办方/出演团体官方推文、主办方/出演者官方活动页与会场官网日历）。
- **确认为官方月度排期图出处**：**8 场**（6月、7月、9月官方日程图），在数据库标明 `note: 来源为月度排期图`。
- **仍仅非官方来源**：**61 场**（Eventernote / LiveFans / Wikipedia），已按规范全部标明 `note: 仅非官方来源`（保留原有多部制或活动取消说明）。
- **补全会场**：2021-01-24「ゲキモリdeヤバイバーVol.5」根据主办方「アイドル侍」官方推文（https://x.com/idol_zamurai/status/1348979604732534790）补全会场为 `club asia`，并补全开场/开演时间（11:00 / 11:30）。
- **修正记录**：对 009 验收中发现的 2021-07-23 早安推文错配、标题错误及 Wikipedia 冗余引用等进行了系统性订正。

## 3. 关键信息修正记录

1. **2021-01-24「ゲキモリdeヤバイバーVol.5」（ID 84）**：
   - **问题**：原会场为「未确认」，开场/开演时间为空。
   - **新出处**：主办方「アイドル侍」官方情报解禁推文（https://x.com/idol_zamurai/status/1348979604732534790）。
   - **修正结果**：会场填入 `club asia`（会场表新增 ID 114，容纳人数 300，东京都涩谷区圆山町1-8，官网 https://clubasia.jp/），开场时间补齐为 `11:00`，开演时间补齐为 `11:30`。

2. **2021-07-23「HEROINES FES vol.2」（ID 124）**：
   - **问题**：原出处误使用了成员心花りり于 2021-07-20 发布的早安出演帖（`1417258596375568400`），原标题误记为「HEROINES FES vol.04」。
   - **新出处**：出演者东京女子流官方网站公演详情页（https://tokyogirlsstyle.jp/live/detail.php?id=1090154）。
   - **修正结果**：标题更正为正确的「HEROINES FES vol.2」，出处更新为官方详情页，补齐开场/开演时间（15:00 / 16:00），保留 `note: 新曲披露公演`。

3. **核心历史公演官方出处补全**：
   - **2020-07-19 デビューLIVE（ID 1）**：原出处为 Wikipedia，替换为官方 X 当日 90 名限定出道成功御礼推文（https://x.com/i/status/1284838364802244608）。
