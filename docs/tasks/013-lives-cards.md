# 公演页改为卡片形式并配图
## 目标
公演页（lives.html）由列表改为大小统一的卡片网格（参照已验收的歌曲页 004 卡片样式），每场演出配一张图。
## 卡片
- 统一尺寸：电脑 4–5 列、手机 2 列；显示图片、日期（JST）、公演名、会场、类型标签（沿用现有颜色）
- 保留现有按类型/年份筛选；点击进入 `lives.html?l=ID` 详情（信息、出处、出演成员、相关图片），浏览器前进后退可用
- 图片固定框内 `object-fit: contain`，不裁剪、不变形；无图显示应援色占位
## 配图（数据）
- 新增 `lives.cover_image_id`（导出为 `cover`），并允许 `image_lives` 关联多张
- 优先级：1) 已在 images 表中、来源推文就是该场出演告知/当日帖/タイムテーブル的图片 → 直接关联；2) @iLiFE_official 该场的告知图、タイムテーブル、当日现场照 → 下载到 img/ 并登记 images；3) 主办方官方 X/官网的告知图；4) 找不到则占位
- 只用官方图片；每张图必须真的打开确认与该场演出对应（标题/日期出现在图或推文中）；不得拼接或猜测 URL/ID；所有请求设超时（curl -m 20）
- 按年份分批提交并推送分支
