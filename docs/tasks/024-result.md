# 024 结果：里程碑公演改用官方公告为源，并补全开场/开演时间

## 结论先说

原定的「2023 年 65 场仅非官方来源公演升级」**做不了**，原因已查实（见下「渠道排查」）。
过程中发现一个更实在的问题并已修完：**27 条里程碑公演全以 Wikipedia 为源、开场/开演时间全空**，
其中 10 条有官网现存公告可覆盖，已改官方并补时间。

## 渠道排查（为什么 2023 那 65 场做不了）

| 渠道 | 结果 |
|---|---|
| 官网 `topics/` 列表页 | 只显示最近 10 条，无分页 |
| 官网 `topics/detail/index/<id>` 详情页 | **仍在线（HTTP 200）**，`recordDay`/`ttl3` 结构可解析 |
| ID 段 900–2050 全量探测（1150 次请求） | 仅 21 条有效，最早 2023-04-12，**2018–2022 全部已删** |
| Wayback CDX API | 仍返回「Internet Archive: Temporarily Offline」 |
| Wayback availability API | 可用，能取单页快照（2023-09-22 快照证实当时列表也只有 5 条 2023 公告） |
| X 站内关键词搜索 | 需登录，不可用 |
| 官网 sitemap | `sitemap.xml` 只有静态页；`sitemap_index.xml` 是 JamClip 默认页 |

现存 21 条公告全是巡演/TIF/成员异动/票务类，没有单场对盘告知。所以 2023 年那 65 场
「仅非官方来源」的记录**没有任何官方渠道可升级**，只能走 018 的路子逐场找主办方官网。
