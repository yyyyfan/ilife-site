# 补全所有演出（第一阶段：数据结构 + 2020–2021 年）
## 背景
`lives` 表现只有 36 场（主要是主催大型公演，来源多为 Wikipedia）。地下偶像每年有大量对バン、フェス、发售活动、生诞祭等，需要全部收录。全量数据量大，分阶段按年份做；本单负责建立结构并完成 2020、2021 年。后续年份另开任务单，沿用同一流程。
## 数据结构（先做）
- `lives` 增加：`type`（ワンマン/主催/対バン/フェス/リリイベ/生誕祭/配信/その他）、`open_time`/`start_time`（可空）、`note`、`setlist`（可空，暂不强制）、`is_headliner`（主催/ワンマン为 1）；必要时新增 `live_members`（当天出演成员，可空）
- `venues` 增加：`address`、`capacity`、`url`（可空，有出处才填）
- export.py 增加检查：日期格式、同日同会场去重、type 取值合法、每场有 source；`data/lives.json` 导出新字段；现有 36 场保持不变并补 type
- 公演页与日历页能显示新字段并可按 type 筛选（保持现有风格，不大改布局）
## 数据来源（按优先级）
1. 官方网站 schedule / news
2. @iLiFE_official 的出演告知、当日「本日の出演」、タイムテーブル帖
3. 主办方/会场官网的活动页
4. Wikipedia、livefans 等仅作补充，需与 1–3 交叉核对
每场必须有至少一个出处 URL；日期用 JST；取消/延期的演出标注 `note`，不要删除。查不到的字段留空，不得猜测。
## 范围
本单只补 2020-06（结成）至 2021-12-31 的演出。新会场一并登记到 venues。
